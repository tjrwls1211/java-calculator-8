# 프리코스 1주차 과제 – 문자열 덧셈 계산기
> 입력 문자열에서 숫자를 추출하여 합을 구하는 프로그램을 구현한다.

## 1. 요구 기능 목록

---
- [x] 입력 문자열을 `Console.readLine()`으로 입력
- [x] 빈 문자열(`""`) 입력 시 0을 반환
- [x] 쉼표(,) 또는 콜론(:)을 구분자로 분리하여 각 숫자의 합을 계산
  - 예: `"1,2:3"` → `6`
- [x] 커스텀 구분자를 지정 가능
  - 문자열 앞부분이 `"//{구분자}\n"` 형태일 경우 해당 구분자를 사용
  - 예: `"//;\n1;2;3"` → `6`
- [x] 숫자가 아닌 값이나 음수가 입력되면 `IllegalArgumentException`을 발생
- [x] 구분된 문자열을 정수로 변환하여 합계를 계산
- [x] 계산 결과를 `결과 : [값]` 형식으로 출력

## 2. 예외

---
입력 값이 잘못된 형식인 경우  
`IllegalArgumentException`을 발생시킨 후 애플리케이션은 종료되어야 한다.

다음과 같은 경우 이외의 입력은 모두 예외가 발생한다.
- 빈 문자열(`""`)
- 쉼표(`,`) 또는 콜론(`:`)으로 구분된 양의 정수 입력
- `"//[구분자]\n"` 형태의 커스텀 구분자를 사용한 양의 정수 입력
