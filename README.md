# 프리코스 1주차 과제 – 문자열 덧셈 계산기
> 입력 문자열에서 숫자를 추출하여 합을 구하는 프로그램을 구현한다.

## 1. 요구 기능 목록

---
- [x] 입력 문자열을 `Console.readLine()`으로 입력
- [x] 빈 문자열(`""`) 입력 시 0을 반환
- [x] 쉼표(,) 또는 콜론(:)을 구분자로 분리하여 각 숫자의 합을 계산
  - 예: `"1,2:3"` → `6`
- [x] 커스텀 구분자를 지정 가능
  - 문자열 앞부분이 `"//{구분자}\n"` 형태일 경우 해당 구분자를 사용
  - 예: `"//;\n1;2;3"` → `6`
- [x] 숫자가 아닌 값이나 음수가 입력되면 `IllegalArgumentException`을 발생
- [x] 구분된 문자열을 정수로 변환하여 합계를 계산
- [x] 계산 결과를 `결과 : [값]` 형식으로 출력

## 2. 예외

---
입력 값이 잘못된 형식인 경우  
`IllegalArgumentException`을 발생시킨 후 애플리케이션은 종료되어야 한다.

다음과 같은 경우 이외의 입력은 모두 예외가 발생한다.
- 빈 문자열(`""`)
- 쉼표(`,`) 또는 콜론(`:`)으로 구분된 양의 정수 입력
- `"//[구분자]\n"` 형태의 커스텀 구분자를 사용한 양의 정수 입력

## 3. 기능 명세

---


> 1번의 요구 기능 목록 기반으로 실제 구현된 세부 동작을 정리

| 번호 | 기능명 | 설명 | 예시 입력 | 기대 출력 / 동작 |
|:--:|:--|:--|:--|:--|
| 1 | 사용자 입력 처리 | `Console.readLine()`을 사용해 문자열을 입력받는다. | `1,2,3` | 입력값을 문자열로 저장 |
| 2 | 빈 문자열 처리 | 입력이 `""` 또는 공백일 경우 0을 반환한다. | `""` | `결과 : 0` |
| 3 | 기본 구분자 파싱 | 쉼표(`,`) 또는 콜론(`:`)을 기준으로 숫자를 분리한다. | `1,2:3` | `결과 : 6` |
| 4 | 커스텀 구분자 파싱 | `"//[구분자]\n"` 형태의 커스텀 구분자를 인식하여 숫자를 분리한다. | `"//;\n1;2;3"` | `결과 : 6` |
| 5 | 숫자 검증 | 분리된 각 문자열이 유효한 양의 정수인지 검증한다. | `"a,2,3"` / `"-1,2,3"` | `IllegalArgumentException` 발생 |
| 6 | 예외 처리 | 잘못된 입력 형식이거나 음수·문자 포함 시 `IllegalArgumentException` 발생 후 종료한다. | `"1,,2"` / `"//;\n"` | 예외 메시지 출력 후 프로그램 종료 |
| 7 | 숫자 합산 | 검증된 모든 숫자를 더해 합계를 계산한다. | `1,2,3` | `결과 : 6` |
| 8 | 결과 출력 | 계산 결과를 `"결과 : [값]"` 형식으로 출력한다. | `1:2,3` | `결과 : 6` |


## 4. 클래스별 역할 요약

---

| 클래스명 | 역할 | 주요 책임 |
|:--|:--|:--|
| `Delimiter` | 입력 문자열에서 기본(`, :`) 또는 커스텀 구분자를 추출 | 커스텀 구분자(`//;\n`) 형식 검증 및 정규식 패턴 생성 |
| `ValidatedNumber` | 개별 숫자 문자열의 유효성 검증 및 변환 | 빈 문자열, 음수, 숫자 아님 등 예외 처리 후 정수 변환 |
| `NumberGroup` | 여러 숫자들을 관리하고 합계를 계산 | 문자열을 구분자로 split → `ValidatedNumber` 객체로 래핑 → 합산 수행 |
| `StringAddCalculator` | 전체 계산 흐름 조립 및 결과 반환 | 입력값 검증, 구분자 생성, 숫자 그룹 생성 후 `sum()` 반환 |
| `Application` | 프로그램의 진입점 | 사용자 입력을 받아 `StringAddCalculator`를 실행하고 결과 출력 |
